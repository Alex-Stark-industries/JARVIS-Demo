Get started in minutes

Three steps to talking with Jarvis

Install Ollama

Install the free local AI engine from ollama.com, then pull the model once: ollama pull qwen2.5:3b

Download Jarvis

Grab JARVIS-Voice-Agent-Setup.exe from the releases page. The installer is per-user — no admin rights needed.

Run & talk

Launch Jarvis from the Start menu. Type in any supported language, or open voice mode and hold Space to speak.
